使用说明

1. 实时看板

左侧选择标的，右侧展示价格K线与13个因子。每张因子卡显示当前读数、评分、状态档位、近60日走势与历史分位；点击卡片可查看该因子的含义、作用、公式与五档状态说明，并可让大模型结合当前行情做深度解读。

2. 综合评分

只有具备多空方向的因子参与综合评分（Σ评分×权重/Σ权重）。ATR波动率、量比、换手率、振幅只反映风险与活跃度，不参与多空判断。

3. 策略回测

选择模板或让 AI 生成代码，点击运行即可得到资金曲线、夏普、最大回撤、胜率与交易明细。信号按“当日收盘生成、次日开盘成交、双边收费”计算，贴近A股实际。

4. 数据源

默认自动选择：QMT（若已安装登录）→ akshare → 内置模拟。模拟数据用于离线演示与逻辑验证，界面会标注「模拟行情」。QMT 接入点已预留，后续可接实盘交易。

5. Windows 打包

源码目录下运行 build_win.bat 可生成单文件 exe，双击即用，无需安装 Python。Win10/Win11 通用。
